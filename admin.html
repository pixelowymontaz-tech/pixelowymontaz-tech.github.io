Pierwsza konfiguracja

Robisz to tylko raz. Wklejasz token z GitHuba i ustawiasz hasło. Token zostanie zaszyfrowany tym hasłem, a potem logujesz się już samym hasłem, z każdego urządzenia.

  1. Otwórz tworzenie tokenu na GitHubie
  2. „Repository access” → Only select repositories → wybierz pixelowymontaz-tech.github.io
  3. „Permissions” → Contents: Read and write → Generate token → skopiuj

Najlepiej 3–4 przypadkowe słowa, np. „lutownica-kaktus-orbita-7”. Nie używaj hasła z innych stron.
